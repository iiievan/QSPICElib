# BAS316 — 0.1.0-preview

Высокоскоростной диод NXP, SOD323, 100 В / 250 мА по паспортным условиям.
Основа: приложенный даташит NXP 2004-02-04 и пользовательская заготовка
из мастера QSPICE. **Третий пользовательский прогон: 22 PASS, 0 WARN, 0 FAIL**
на четырёх текущих стендах. Детальные значения — `tests/TEST_RESULTS.md`.

```spice
.lib BAS316.txt
D1 anode cathode BAS316
```

Физические выводы: 1 — катод, 2 — анод. Порядок узлов SPICE — A K.

DC-подгонка основана на приблизительных типовых точках рис. 3:
0,60/0,72/0,87/1,04 В при 1/10/50/150 мА. Табличные максимумы
0,715/0,855/1/1,25 В проверяются отдельно. Ёмкостная подгонка
сохранена из исходника и прошла сверку с рис. 6.
Оригинал без изменений — `source/user_BAS316_original.txt`.

Горячая статическая утечка при 150 °C составляет 10,1873 мкА
при 25/75 В (max 30/50 мкА). Измеряется через DC-развёртку.
Текущий диагностический recovery-стенд дал 1,79431 нс; TT и trr
разные величины. Он не повторяет генератор рис. 7 в точности.

## Ограничения

- Прежний горячий transient-стенд дал `Timestep too small` при t=0.
  DC-проверка подтверждает утечку, но не устраняет отказ горячей динамики.
- Простая D-модель не воспроизводит отдельно IR(VR) при 25 и 75 В:
  до пробоя утечка почти постоянна.
- `Vrev=100` и `Iave=0.25` — аннотации рейтинга, не физические ограничители.
- Не подогнаны лавинный пробой, саморазогрев, Vfr и разброс экземпляров.

Preview сохранён из-за этих ограничений. Для схем, которым нужна
динамика при 150 °C, требуется отдельная проверка.

```bash
KEEP_RAW=1 ./run_tests.sh BAS316
```

Повтор текущих прошедших тестов без изменения модели не обязателен.
Они остаются частью общей регрессии библиотеки.
