# FJP5027: исправления после первого прогона

Распаковать с заменой файлов в корень библиотеки. Общие QSCH не включены и
не перезаписываются. FJP5027_CANDIDATE_V1 сохранена побайтно, без подгонки
на этот прогон. Изменён только расчётный процесс и сохранение результатов.

## Что обнаружено

1. 27 из 28 случаев рассчитаны. В gain при -25 C QSPICE выдал
   Gmin/Source stepping failed и Fatal error: Iteration limit reached.
   Предупреждения Ignoring shorted resistor R_K относятся к адаптеру,
   где K и E заземлены, и сами по себе не являются этой ошибкой.
2. Резистивное переключение при 25 C сошлось: изменение времени спада
   0.00789%, хранения 0.0351%, средней мощности 0.00161% между двумя
   самыми мелкими шагами.
3. CIL: время спада не сошлось. При Tmax=1 ns оно 1.85603 ns,
   при Tmax=0.5 ns - 0.0699014 ns. Энергия при этом меняется на 0.235%.
   Стабильная энергия не подтверждает точность времени спада.
   В CIL также получен пик IB около -1.73 A: этот диагностический режим
   требует отдельной проверки драйвера/условий перед физическими выводами.
4. Типовые кривые пока не совпадают. Точки табличных максимумов проходят,
   но это не означает завершённую калибровку модели.

## Пятый стенд

В нарисованном QSCH пробник развёрнут:

```spice
V_IB base b_feed 0
```

Нужно:

```spice
V_IB b_feed base 0
```

Это нулевой источник: его разворот меняет знак измеренного IB, но не
электрический режим и не VBE. В версии 2 скрипт делает это исправление
в сгенерированном CIR, отмечает в отчёте и проверяет IB=+0.3 A при IC=1.5 A.

Ручные одинаковые числа POL=+/-1 соответствуют зеркальным демомоделям.
При сохранённом Rb=10 ohm и IB=1.5/5=0.3 A падение внутри модели равно 3 V.
Это объясняет внешнее VBE около 3.98 V. При Rc=0.5 ohm падение при 1.5 A
равно 0.75 V, что согласуется с внешним VCE около 0.924 V.
Это не результаты FJP5027. В присланном автоматическом прогоне кандидата
при 25 C: VCEsat=0.444985 V, VBEsat=1.07169 V.

## Что исправлено в коде

- При выходных/gain-измерениях из общей схемы выбирается соответствующая
  независимая ветвь. Неиспользуемые DUT и старый незащищённый hFE-монитор
  исключаются из расчётного CIR. Gain начинается с VBE=0.4 V, а не с нуля.
  Успех этой подготовки на холодном случае нужно подтвердить QSPICE.
- После QPOST и оценки полного CSV сохраняются точные метрики и компактный
  NPZ с исходными точками для рисунков. Границы и пики сохраняются; по
  прореженным точкам критерии повторно не вычисляются.
- QRAW и большой CSV удаляются после каждого случая, включая завершившиеся
  с ошибкой; журналы и нетлисты сохраняются. Во время отдельной симуляции
  QRAW всё ещё создаётся временно.
- Обычная диагностика исключает оба больших формата. Для отладки они
  включаются только явными --keep-raw/--keep-waveforms при запуске и
  --raw/--waveforms при сборе архива.
- Старый отчёт можно пересобрать после ручного удаления CSV/QRAW: остаются
  исходные метрики и PNG. В папке review приложена такая пересборка.
- Проверены 25 тестов Python и все 28 CIR из настоящих экспортов QUX.
  Новых нативных симуляций QSPICE при исправлении не было.

## Следующий запуск

```bat
run_all.cmd --only gain saturation
collect_diagnostics.cmd
```

Это короткая проверка холодного gain и пятого QSCH. После неё можно
продолжать калибровку статических параметров; CIL tF пока остаётся
непринятым независимо от внешнего вида осциллограмм.
