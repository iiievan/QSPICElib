# SOLOON S6061NS-40DF — application validation

Эта папка **не является частью универсальной модели FDS4559**. Здесь живут
проверки конкретного изделия, которые используют компоненты QSPICElib как
уже верифицированные строительные блоки.

Текущий стенд:

```text
tests/S6061NS_halfbridge_static_test.cir
```

Он проверяет конкретную цепочку прототипа:

```text
3.3-V logic -> 74HCT244 -> 470R -> FDS4559 N
3.3-V logic -> ULQ2003A -> 1k/1k -> FDS4559 P
VBUS = 24 V
I = 0.15 / 0.50 A
TEMP = -35 / +25 / +60 C
```

Поэтому его `.expect` содержит **требования изделия**, а не параметры
даташита FDS4559.

Будущие 18-V/24-V варианты, модель BLDC, INA181, current loop, Hall
commutation и RS-485-related проверки должны добавляться здесь или в другой
папке конкретного устройства, а не в каталоги компонентов.

Запуск отдельно:

```bash
./run_tests.sh applications/S6061NS-40DF
```

Запуск вместе с core regression всей библиотеки:

```bash
./run_tests.sh --all
```

Последний зафиксированный статический прогон перед переносом стенда дал PASS
по всем application hard requirements при трёх температурных шагах. Перенос
в `applications/` не меняет netlist/expect, только отделяет требования изделия
от универсальной модели компонента.
