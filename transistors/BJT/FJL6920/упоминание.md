# FJL6920: упоминание и план проверки

Статус: **DOCUMENTED_NOT_SIMULATED**. В папку добавлены даташит и план работ.
Электрическая модель ещё не импортирована, нативные расчёты QSPICE и приёмка не выполнялись.

## Чем интересен

Силовой высоковольтный BJT для проверки ВАХ, спада hFE при большом токе и насыщения коллекторной области.

| Параметр | По выбранному даташиту |
|---|---|
| Тип / POL общих стендов | NPN / +1 |
| Модуль VCEO | 800 В |
| Модуль непрерывного IC | 20 А |
| Корпус | TO-264-3LD |
| Изготовитель документа | onsemi / Fairchild |

Пределы напряжения и тока не являются одновременно допустимой рабочей точкой;
рабочие траектории проверяются отдельно по паспортной SOA.

## Что учесть перед импортом

В карточке FJL6920 на LTwiki отсутствуют TF и TR. До извлечения заряда и проверки времени рассасывания её динамику нельзя считать настроенной. Отдельный высоковольтный предел VCBO=1700 В не заменяет VCEO=800 В.

## Что ещё проверить

- [ ] Оцифровать статические кривые PDF: IC(VCE), hFE(IC), VCEsat(IC) и VBE(IC); выписать токи базы и температурные условия каждой кривой.
- [ ] Воспроизвести резистивный тест VCC=200 В, IC=10 А, RL=20 Ом, IB1=2 А, IB2=-4 А. Цели таблицы: tSTG <= 3 мкс; tF typ=0.15 мкс, max=0.2 мкс. Микросекунды проверены по изображению PDF: текстовый экстракт ошибочно показывает ms.
- [ ] Проверить шаг интегрирования, определения tSTG/tF и температурную зависимость; завершение расчёта само по себе не означает соответствия.
- [ ] Сохранить исходную карточку, её происхождение и все изменения; создать отдельный профиль общих стендов.
- [ ] Сформировать MD-отчёт с исходными точками PDF и результатами QSPICE, условиями сравнения и статусом каждой проверки.

## Тепловой этап

Вложенный PDF содержит RthetaJC, но отдельная кривая Ztheta(t) в нём не найдена. Для физической динамической тепловой модели нужны дополнительные данные; Cth по одному RthetaJC не определяется.

Тепловая сеть пока не извлечена и не подключена. Для проверки электропараметров сначала
задать изотермическую температуру; для нагрева нужен отдельный расчёт мощности и Tj(t).
Паспортная SOA остаётся внешним ограничением и не выводится из факта сходимости SPICE.
