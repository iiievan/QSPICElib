# v11: короткое сравнение четырёх готовых моделей FJP5027

Запуск из этой папки:

```bat
compare_candidates.cmd
```

Повторять `calibrate_refine.cmd` для этого этапа не нужно. Большой подбор v9 уже завершён.
Команда работает с прежним установленным QSPICE и общими QSCH; дополнительных схем рисовать не требуется.

## Кандидаты

| ID | Происхождение | Что уже известно |
|---|---|---|
| mex_v8 | Нативный checkpoint v8 | 10 полных PASS, прежняя база сравнения |
| mex_guarded_eval21 | Оценка 21 из истории v9 | 11 sampled PASS, ноль sampled потерь; полные кривые ещё не проверены |
| mex_v9_final | Финальный результат v9 | 11 полных PASS, две потери прежних PASS, Cobo настроена через TRAN |
| ltwiki_gp | Найденная KSC5027 | Нативное сравнение с нашим даташитом ещё не выполнялось |

Исходники и хеши: [manifest.json](calibration/comparison_v11/manifest.json).
Для KSC5027 сохранён [оригинал](calibration/comparison_v11/ltwiki_original.txt).
В запускаемой копии оставлены те же электрические коэффициенты, удалены только
справочные Vceo/Icrating/mfg и неиспользуемые AKO-алиасы. Неявная TNOM исходной карточки сохранена.
Наличие имени изготовителя в найденной записи не подтверждает её официальное происхождение.

## Как проходит запуск

1. Проверяются исходные хеши профиля, установленной модели, кривых и четырёх карточек.
2. Для каждого MEXTRAM выполняется существующая процедура Cobo через малосигнальный TRAN:
   GP-контроль, начальная матрица сходимости, до четырёх коррекций CJC и повторная матрица.
   Изменённая CJC записывается в отдельную итоговую карточку кандидата.
3. Для найденной GP Cobo только измеряется с проверкой сходимости; коэффициенты GP не подгоняются.
4. Каждая итоговая карточка проверяется в 15 DC-случаях / 19 кривых с теми же эталонами и допусками.
   MD, PNG и метрики считаются по полному CSV, затем большие файлы очищаются.
5. Для рекомендации обязательны все 15 SIMULATED, конечные метрики всех 19 кривых,
   четыре табличных PASS, правильный ток базы и сохранение прежних десяти PASS.
   Меньшая ошибка или большее число других PASS не отменяют это условие.
6. Среди допущенных по DC выбирается наибольшее число PASS, затем меньший худший нормированный P95.
   Рекомендация по DC не равна полной приёмке модели. Саморазогрев и переключение не проверяются этим запуском.

Всего 60 DC-случаев. При обычной одной коррекции CJC получится около 52 TRAN-расчётов;
верхний предел при четырёх коррекциях у каждого MEXTRAM — 62 TRAN. Это отдельные проверки
готовых параметров; оптимизатор и 150 прошлых оценок не повторяются.

## Отчёт и диагностика

- `comparison_results/<UTC>/report.md`: сводная таблица и ссылки на отчёты всех кандидатов.
- `comparison_state.json`: полный результат, критерии выбора, хеши и applied=false.
- `FJP5027_calibration_diagnostics.zip` автоматически формируется в конце этого запуска.
  Его и отправить для следующего разбора; ручной сборщик старых results для этого этапа не нужен.

Нативный .ac MEXTRAM не запускается: проверка Cobo имеет явный метод TRAN-admittance.
Критерий +/-2% относится к настройке типовой точки 60 пФ, а не к гарантии производителя.
Установленная GP и profile.json этой командой не заменяются. QSCH не перерисовываются.
QRAW и полный waveforms.csv удаляются после обработки; исключаются из диагностики.

Подготовка CIR без симулятора:

```bat
compare_candidates.cmd --prepare
```

Такой запуск имеет статус PREPARE_ONLY и не является нативным испытанием.
При нестандартной установке: `compare_candidates.cmd --qspice-dir "D:\Tools\QSPICE"`.
