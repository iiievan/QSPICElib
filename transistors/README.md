# Транзисторы QSPICE

Общие стенды находятся в одном месте.

| Каталог | Назначение |
|---|---|
| [_common/bjt](_common/bjt) | ВАХ, ёмкости, резистивное и индуктивное переключение, насыщение, энергия выключения. |
| [_common/fet](_common/fet) | Общие схемы для Si MOSFET, SiC MOSFET и normally-off GaN. Для конкретного ключа выбираются модель, распиновка и режим. |
| [BJT](BJT), [Si](Si), [SiC](SiC), [GaN](GaN) | Карточки приборов, даташиты и заготовки будущих исследований. |

Адаптер 00_device.cir находится рядом со схемами каждого семейства. Запуск и история FJP5027 описаны в [его папке](BJT/FJP5027/README.md).

Для установки переименуй прежний каталог transistors в резервную копию и положи на его место каталог из архива. Простое наложение файлов оставит старые дубли на диске.
