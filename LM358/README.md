# LM358 — 0.1.0-preview

Поведенческая модель **onsemi LM358**, по приложенному LM358/D Rev.36,
September 2024. Готова к первому прогону в QSPICE; статус валидации предварительный.

- `LM358.txt`: один канал `LM358` и обёртка физического корпуса `LM358_DUAL`.
- `datasheets/LM358-D.PDF`: исходный даташит, без изменений.
- `tests/`: 11 стендов, 95 измерений, 246 сравнений с учётом шагов.
- [Описание тестов](tests/TEST_README.md): происхождение чисел и ограничения.
- [Статус проверок](tests/TEST_RESULTS.md): что действительно выполнено.

```spice
.lib LM358.txt
* IN+ IN- VCC VEE OUT
X1 in feedback vcc vee out LM358
.temp 60
```

Полный корпус: `X1 outA minusA plusA vee plusB minusB outB vcc LM358_DUAL`.
Для QSPICE можно использовать пятивыводной символ `.subckt` с тем же порядком
выводов; номер физического вывода корпуса и позиция аргумента одиночного ядра
не совпадают. Графический `.qsym` в этой версии не добавлялся.

Реализованы входные токи, смещение и его типовой дрейф, конечное усиление,
DC CMRR/PSRR, два частотных полюса, slew rate, выходные ограничения и
потребление через реальные выводы питания. Температурные зависимости,
не обеспеченные даташитом, явно отмечены как неизвестные.

**LM358: 0…+70 °C. При −35 °C модель — экстраполяция.** Ни холодный
функциональный PASS, ни ограничение тока в модели не расширяют рейтинг кристалла.
INA181A1 в этом изменении не добавлялся.

Из корня библиотеки:

```bash
./run_tests.sh LM358
```
