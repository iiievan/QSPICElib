# INA181A1 0.1.0-preview - модель и приёмка

Источник: `../datasheets/ina181.pdf`, TI SBOS793H, November 2023.
Проверяется только **INA181A1**, gain 20 V/V.

## Стенды

| Стенд | Покрытие |
|---|---|
| `INA181_dc_test` | Gain, gain error, VOS, IIB, IIO при типовых условиях |
| `INA181_common_mode_test` | VCM −0,2…26 В и CMRR |
| `INA181_supply_temp_test` | VS 2,7…5,5 В, PSRR, IQ, −40…125 °C |
| `INA181_output_ref_test` | REF, двунаправленный сигнал, swing к обеим шинам |
| `INA181_ac_test` | Полоса A1 350 кГц, спад усиления |
| `INA181_slew_test` | Slew rate 2 В/мкс и установление |

Типовые значения проверяются как WARN, гарантированные min/max и
функциональные инварианты — как hard FAIL. Температурные зависимости, которых
нет в таблице, не выдумываются: сохраняется номинал, а стенд проверяет предел.

Не покрываются шумовая плотность, ESD, разрушающие режимы, саморазогрев,
статистическое распределение и точное поведение при отключённом питании.

```bash
KEEP_RAW=1 ./run_tests.sh INA181
```

До фактического QSPICE/QPOST-прогона статус остаётся preview.
