# INA181A1 - 0.1.0-preview

Самостоятельная поведенческая модель **TI INA181A1** по SBOS793H,
November 2023. Это вариант A1 с усилением 20 В/В.

```spice
.lib INA181A1.txt
* IN+ IN- VS GND REF OUT
XU1 inp inm 5 0 2.5 out INA181A1
```

Реализованы фиксированное усиление, VOS и его типовой температурный дрейф,
DC CMRR/PSRR, диапазоны питания/common-mode, выходные ограничения, токи
покоя/входов, однополюсная полоса 350 кГц и slew rate 2 В/мкс.

Не реализованы достоверный шум, ESD и разрушение, саморазогрев, статистика,
точная внутренняя схема при выключенном питании и пакетные паразитные элементы.
Типовые значения не являются гарантией каждого реального экземпляра.

Приёмка:

```bash
KEEP_RAW=1 ./run_tests.sh INA181
```

До фактического прогона QSPICE/QPOST модель имеет статус `preview`.
