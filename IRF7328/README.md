# IRF7328 — 0.1.1-preview

Два независимых P-канальных MOSFET, −30 В, SO-8. Источник:
приложенный IR PD-94000 от 04-Oct-2000 и заготовка мастера пользователя.
**Третий пользовательский прогон: 26 PASS, 2 WARN, 0 FAIL** на шести
стендах. Статика, AC, Qg и независимость каналов прошли текущие критерии;
типовая динамика выключения ещё отличается.

## Подключение

Файл содержит модель одного кристалла и две альтернативные обёртки:

```spice
.lib IRF7328.txt
* Один канал, D G S B:
M1 drain gate source source IRF7328
* Два канала, D1 G1 S1 D2 G2 S2:
X1 d1 g1 s1 d2 g2 s2 IRF7328_DUAL
* SO-8, физический порядок 1..8:
X2 s1 g1 s2 g2 d2a d2b d1a d1b IRF7328_SO8
```

Выбрать подходящий способ. Для отдельного канала — P-MOS с префиксом M;
для обёртки — символ подцепи X с указанным порядком узлов.

| Вывод SO-8, вид сверху | Назначение |
|---:|---|
| 1 / 2 | S1 / G1 |
| 3 / 4 | S2 / G2 |
| 5, 6 | D2 |
| 7, 8 | D1 |

Пары стоков связаны через 1 мкОм как численные перемычки;
это не измеренная модель выводов. Общей тепловой сети кристаллов нет.

## Ограничения

- Два WARN выключения существенны для расчёта потерь: времена примерно
  в 2,3 раза меньше типовых, хотя табличные максимумы не превышены.
- Внутренний Rg=6 Ом сохранён как непроверенная оценка; внешний RG=6 Ом
  switching-стенда подключён отдельно. Их нельзя смешивать.
- TT=18 нс не подтверждает табличные body-diode trr/Qrr; отдельного
  прогона при IF=2 А, di/dt=100 А/мкс пока нет.
- Температурные коэффициенты исходника не приняты по RDS(T)/VTH(T).
  Горячая утечка проверена только при табличных 70 °C.
- Нет self-heating, общей тепловой сети, индуктивностей корпуса и разрушения.
  `Vds`, `Ids`, `Ron`, `Qg` — аннотации, а не физические ограничители.
