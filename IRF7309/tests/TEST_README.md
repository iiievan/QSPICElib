# IRF7309 0.1.0-preview — этап 1

Источник параметров: International Rectifier / Infineon IRF7309,
`PD-9.1243B`. Модели каналов происходят из KSKelvin-Github/Qspice commit
`c51d63f46173b16c4b5c309ac31e081df6b4c5e4`, GPL-3.0.

| Проверка | N-channel | P-channel |
|---|---:|---:|
| `VGS(th)`, `|ID|=250 мкА` | 1…3 В | −1…−3 В; проверяется модуль |
| `RDS(on)`, `|VGS|=10 В` | ≤50 мОм при 2,4 А | ≤100 мОм при 1,8 А |
| `RDS(on)`, `|VGS|=4,5 В` | ≤80 мОм при 2,0 А | ≤160 мОм при 1,5 А |
| `IDSS`, `|VDS|=24 В`, 25 °C | ≤1 мкА | ≤1 мкА |
| body diode, `|IS|=1,8 А` | `VSD≤1,0 В` | `|VSD|≤1,0 В` |

Проверка `V(BR)DSS=±30 В` не выполняется: параметр `VDS` в этой компактной
модели является метаданным и не задаёт достоверный лавинный пробой. Gate
leakage, абсолютные максимумы и разрушение также не являются предметом
безопасной SPICE-приёмки.

Температурный sweep пока не добавлен: в исходных строках отсутствуют явно
заданные температурные коэффициенты канала. Сначала принимается только
табличное поведение при 25 °C.

```bash
KEEP_RAW=1 ./run_tests.sh IRF7309
```
