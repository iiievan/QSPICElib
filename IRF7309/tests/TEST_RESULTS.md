# IRF7309 — статус после второго прогона пользователя

Повторный журнал `run_log(1).txt`: 16 PASS, 4 WARN, 1 FAIL.
QSPICE/QPOST для изменённого стенда ёмкости здесь отсутствует; приведённые
числа получены из присланного прогона, а не из новой симуляции.

| Стенд | Фактический повторный прогон | Дальнейшая проверка |
|---|---|---|
| DC | 10 PASS при 25 °C | Заданные гарантированные пределы выполнены |
| Ёмкости | Шесть `NaN` для `FIND abs(I(V...))`; 1 FAIL | Новая схема использует 1-омные резисторы и `FIND abs(V(sense))`; повторить QSPICE/QPOST |
| Qg | N 7,799 нКл, P 7,641 нКл; 25 нКл max выполнен | 2 PASS |
| Переключение | 4 PASS, 4 WARN при импульсе затвора ±10 В | WARN по типовым td(on)/tr N и P; не являются нарушением гарантированных пределов |

Из сохранённого `.qraw` первого прогона с AC-амплитудой 1 В расчёт
`C = |I|/(2*pi*1 MHz)` дал: N 449,9/192,9/119,9 пФ, P 485,4/256,1/185,4 пФ
(Ciss/Coss/Crss). Эти значения нельзя приписывать ещё не исполненному стенду
с измерительными резисторами. Типовые точки даташита: N 520/180/72 пФ,
P 440/200/93 пФ. Расхождение Crss требует проверки модели, если точность
ёмкостей при разных напряжениях критична для проекта.

Ни исходные, ни обновлённые стенды не подтверждают весь привод
противопожарной заслонки: нужны характеристики двигателя, драйвера,
питания, теплового режима и защит, а также проверки моста.
