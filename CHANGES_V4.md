# Версия 4: калибровка DC25

Запуск из `transistors/BJT/FJP5027`:

```bat
calibrate.cmd
```

- Подготовлены три начальных кандидата модели и нативный подбор IS/BF/IKF/VAF/BR/IKR/RB/RC.
- Совместимость NK/NKF проверяется на установленном симуляторе измерением отклика.
- Целевая функция рассчитывается только по нативному QPOST. Все четыре DC-семейства имеют одинаковый суммарный вес; допуски не изменены.
- Улучшенный кандидат устанавливается после тонкой проверки, затем автоматически проверяются 16 статических случаев. При INVALID/табличном FAIL исходная модель восстанавливается.
- Автоматический компактный FJP5027_calibration_diagnostics.zip; QRAW/полные CSV удаляются.
- Пройдены 42 теста Python. Новый нативный подбор должен выполнить пользователь.
- Исходная модель и QSCH при распаковке остаются прежними; параметры заряда и динамика в этой стадии не подгоняются.

Подробности: `transistors/BJT/FJP5027/CALIBRATION.md`.
