* EL354NA v0.2.1 CANDIDATE - optional Fig.4 CTR temperature correction.
* Source: attached EL354N-G Series Rev.6 datasheet, pages 1-4.
* Pins: LED 1, LED 2, collector 4, emitter 3. Example:
* X1 led1 led2 collector emitter EL354NA params: CTR1M=0.5
* CTR1M = IC/IF at IF=1mA and VCE=5V, at 25 C (dimensionless).
* Rank A at 25 C: CTR1M=0.5 .. 1.5. Default 0.5 is its LOW corner,
* not the unspecified typical CTR. Select corners explicitly in a system sim.
* Normalized CTR(IF) is an approximate fit to p.4 Fig.3, VCE=5V, 25 C
* over IF about 0.5 .. 30mA. Typical graphs are not production limits.
* TAU=2u is an illustrative optical time constant, not a fitted typical:
* datasheet only specifies tr/tf <= 18us at its particular test point.
* THERMAL=0 (default): exact legacy output equations; preserves old suites.
* THERMAL=1: approximate temperature correction read from Fig.4, VCE=5V.
* Each IF curve is normalized to itself at 25 C. At 25 C the factor is 1.
* Current interpolation uses clipped linear ramps, avoiding variable TABLE
* ordinates. The temperature tables themselves contain only numeric knots.
* Table knots: IF=0.5,1,5,10,25mA and T=-55..100 C. Piecewise linear.
* Below/above those IF/T knots the correction clamps to the nearest edge;
* this is numerical fallback, NOT validated extrapolation or a worst case.
* The applied current is the filtered optical-drive current; no self-heating.
* LED parameters are unchanged; their SPICE thermal law is NOT curve-fitted.
* Leakage remains Rdark=1G and TAU remains user-set: no thermal data fitted.
* Candidate not executed in QSPICE yet; typical curves are not hard limits.
