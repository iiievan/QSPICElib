# Добавление BAS316 и IRF7328, 2026-10-07

В исходную Qlibin_v1 добавлены два каталога без изменения старых моделей,
стендов, runner и протоколов. В корневой README добавлен раздел о новинках.

| Компонент | Модели | Стенды / измерения | Статус |
|---|---|---:|---|
| BAS316 | D-модель | 4 / 22 | 0.1.0-preview; расчёт DC/Cj, QSPICE не запускался |
| IRF7328 | Один P-MOS + DUAL + SO8 | 6 / 28 | 0.1.0-preview; структурная проверка, QSPICE не запускался |

Исходники пользователя — `source/user_*_original.txt`; приложенные PDF —
`datasheets/`. Модели `.txt` в корне каждого компонента являются рабочими
кандидатами. Исходные `.txt` не подключать одновременно с ними: имена моделей
совпадают. Для новых компонентов предусмотрены `.cir` и `.expect`, которые
автоматически обнаруживает существующий `run_tests.sh`.

BAS316: заменены некорректные Is/N/Rs/XTI/TT; ёмкостная подгонка сохранена.
IRF7328: исправлены Vto/TT, начальные ёмкости пересчитаны, добавлены две
обёртки. Статическая подгонка MOSFET сохранена; динамика и температурная
зависимость требуют прогона. Внутренние 6 Ом Rg пока непроверены.

Запуск в Git Bash из корня:

```bash
KEEP_RAW=1 ./run_tests.sh BAS316
KEEP_RAW=1 ./run_tests.sh IRF7328
```

После этих запусков сохранить или передать `.out` из обоих каталогов tests.
В корне останется отчёт только последнего запуска. Полученные реальные
ошибки/отклонения используются для дальнейшей подгонки без ослабления
даташитных максимумов. Отдельный тест body-diode trr/Qrr IRF7328 ещё не
добавлен; соответствие этим пунктам пока не заявляется.

Справка по модели заряда VDMOS от автора QSPICE (фиксированный Cgs,
нелинейный Cgd и ёмкость перехода body diode):
